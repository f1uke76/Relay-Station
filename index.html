添加新的控制台

在本仓库 main 分支新建一个子目录并放入 index.html， 网址即为 https://f1uke76.github.io/Relay-Station/<子目录名>/； 然后在上面「控制台」区块加一条同样的入口即可。每个页面可以有自己完整的 HTML / CSS / JS。

共用队列要注意：所有页面共享同一个仓库的 Issues。远程下载 App 会读取全部 open Issues， 只执行首行形如 ADD https://... 的指令。其它控制台请避开这个格式， 或改用独立前缀 / 标签，避免被当成下载任务。
