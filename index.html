令牌与私有库说明

保存后令牌会写进私有库的 pat.md，其他端在已持有令牌时会自动比对并同步最新登记。 私有库所有内容都需要认证，因此全新设备首次仍需要一次「一键获取」或打开导出链接—— 零凭证读取私有库在 GitHub 上不允许（等价于把令牌公开）。

令牌只存本机浏览器与手机 App 私有偏好，不进公开控制台仓库、不进 APK。 预填链接含 name=RemoteDL、target_name=f1uke76、issues=write、 contents=write（写 pat.md 必须）、expires_in=none； 生成前请确认 Repository access 只选 RemoteDL。

pat.md 含明文令牌：私有库只有你本人可见，但切勿把仓库转为公开；撤销令牌后请点「删除」清空登记。
